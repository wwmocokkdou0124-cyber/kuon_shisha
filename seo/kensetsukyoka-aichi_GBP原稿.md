```
愛知県稲沢市の行政書士事務所です。建設業許可を中心に、建設業・産業廃棄物・電気工事・リユース（古物）など、事業を営む皆さまに必要な許認可の手続きをお手伝いしています。

【主な業務】
・建設業許可（新規・更新・業種追加・変更届・廃業届）

・産業廃棄物収集運搬業許可（新規・更新・変更、特別管理産業廃棄物、他県での許可）
・電気工事業の登録、みなし登録の届出、主任電気工事士の変更

稲沢市・一宮市・清須市・北名古屋市・あま市・津島市・江南市・小牧市・春日井市など尾張地域と名古屋市を中心に、愛知県全域に対応しています。

・許可を取った後の決算変更届や更新など、毎年の手続きも続けてサポートします
・建設業許可と産廃許可など、関連する許可をまとめてご依頼いただけます

「500万円以上の工事を受けることになった」「元請から許可を取るように言われた」「現場のごみを自社で運びたい」など、まずはお気軽にご相談ください。
```

## サービス（名前と説明。料金は入れない）
### 建設業許可
| サービス名 | 説明 |
|---|---|
| 建設業許可の新規申請 | 許可が必要かの判断から、経営業務の管理責任者・営業所技術者等の要件確認、書類の作成、愛知県への申請まで代行します。 |
| 建設業許可の更新 | 有効期間は5年。満了日の30日前までの申請が必要です。たまっている決算変更届もまとめて対応します。 |
| 業種追加 | 追加する業種の営業所技術者等の確認から、書類の作成、申請まで代行します。 |
| 決算変更届（事業年度終了届） | 決算後4か月以内の届出です。何期分たまっていてもまとめて対応します。 |
| 建設業許可の変更届 | 役員・代表者・経営業務の管理責任者・営業所技術者等・商号・所在地などが変わったときの届出を代行します。 |
| 般・特新規、許可換え新規 | 一般から特定への切り替えや、知事許可から大臣許可への切り替えなどに対応します。 |
| 建設業の廃業届 | 事業をやめるとき、許可を返すときの届出を代行します。 |
| 経営事項審査（経審） | 経営状況分析の申請、技術職員名簿の作成、愛知県への申請までまとめて代行します。 |
| 入札参加資格審査申請 | 経審のあとの、愛知県・市町村の入札参加資格の申請を代行します。 |
| 実務経験証明書の作成 | 資格がない方が実務経験で営業所技術者等になるための証明書の作成と、裏付け資料の整理をお手伝いします。 |

### 産業廃棄物収集運搬業許可
| サービス名 | 説明 |
|---|---|
| 産廃収集運搬業許可の新規申請 | 講習会・車両・経理的基礎の確認から、愛知県への申請まで代行します。 |
| 特別管理産業廃棄物収集運搬業許可 | 廃油・廃酸・廃石綿等などを運ぶための許可の申請を代行します。 |
| 積替え保管ありの許可 | 運ぶ途中で降ろして保管するための許可です。場所選びの段階からご相談いただけます。 |
| 産廃許可の更新 | 有効期間は5年。愛知県から更新の通知は来ないため、期限の管理からお手伝いします。 |
| 産廃許可の変更許可・変更届 | 品目の追加（変更許可）、車両・役員・住所の変更（変更届）に対応します。 |
| 岐阜・三重・静岡の産廃許可 | 積む県と降ろす県の両方で許可が必要です。東海4県の申請をまとめて代行します。 |
| 建設業許可と産廃許可のまとめて取得 | 下請が現場のごみを運ぶには、原則として産廃の許可が必要です。建設業許可とあわせて申請できます。 |
