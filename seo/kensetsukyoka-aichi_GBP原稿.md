## サービス（名前と説明。料金は入れない）
### 建設業許可
| サービス名 | 説明 |
|---|---|
| 建設業許可の新規申請 | 許可が必要かの判断から、経営業務の管理責任者・営業所技術者等の要件確認、書類の作成、愛知県への申請まで代行します。 |
| 建設業許可の更新 | 有効期間は5年。満了日の30日前までの申請が必要です。たまっている決算変更届もまとめて対応します。 |
| 業種追加 | 追加する業種の営業所技術者等の確認から、書類の作成、申請まで代行します。 |
| 決算変更届（事業年度終了届） | 決算後4か月以内の届出です。何期分たまっていてもまとめて対応します。 |
| 建設業許可の変更届 | 役員・代表者・経営業務の管理責任者・営業所技術者等・商号・所在地などが変わったときの届出を代行します。 |
| 般・特新規、許可換え新規 | 一般から特定への切り替えや、知事許可から大臣許可への切り替えなどに対応します。 |
| 建設業の廃業届 | 事業をやめるとき、許可を返すときの届出を代行します。 |
| 経営事項審査（経審） | 経営状況分析の申請、技術職員名簿の作成、愛知県への申請までまとめて代行します。 |
| 入札参加資格審査申請 | 経審のあとの、愛知県・市町村の入札参加資格の申請を代行します。 |
| 実務経験証明書の作成 | 資格がない方が実務経験で営業所技術者等になるための証明書の作成と、裏付け資料の整理をお手伝いします。 |
