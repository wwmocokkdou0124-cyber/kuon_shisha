### 1-2. 問い合わせ導線

良い点（このまま続ける）
- 全記事の最後に「LINE／電話／メール」の3ボタンと「初回相談は無料」「夜間・土日もLINE対応」の文がある
- 「『○○の相談』と送るだけ」「コピペ用テンプレート」（古物商の変更届ページ）は、送る内容に迷わせない良い工夫

直すところ
1. **スマホ固定メニューの「問い合わせ」が別サイトのフォーム**（`https://office-kuon.com/script/mailform/need/`）。スマホ利用者は全体の約3割。他のボタンと同じ `https://kensetsukyoka-aichi.jp/script/mailform/inquire/` にそろえる。（このフォームが動いているかは、こちらの環境からは確認できなかった。スマホで一度送信テストを）
2. **記事のテーマとバナーの文言がずれている**
   - 経審の記事（category9/entry86）：途中のバナーが「『建設業許可の相談』と送るだけ！建設業許可の取得代行いたします」、最後の案内カードが「建設業許可の申請代行（category4/）」→ **経審の代行ページ（category4/entry57.html・165,000円）** への案内に変える
   - 古物商の変更届ページ（category10/entry124）：途中のバナーが「許可が取れるか・いくらかかるか」（新規取得向け）→「変更届が必要か無料で確認します」などに
3. **途中のバナーはメールフォームにだけリンク**している。読者はLINEの方が気軽なので、途中のバナーのリンク先をLINEに変える（または「LINEで相談」ボタンを並べる）
4. **最後の3ボタンに料金が書かれていない**。手続き別の料金（例：経審165,000円、変更届11,000円〜）をボタンの直前に1行入れると、問い合わせ前の不安が減る

## 2. トップページ

### 今の状態
- タイトル：`愛知県建設業許可サポートステーション`（サイト名だけ。地名・「代行」「行政書士」が入っていない）
- 説明文：**空**
- H1：`愛知県建設業許可サポートステーション`
- 中身：ごあいさつ → お困りごと → 6つのメニュー（料金付き）→ 3つの強み → 依頼の流れ → 問い合わせ → 運営者情報。**内容はしっかりしている**
- 3か月で表示48回のみ（＝トップページで検索に出ていない）

### 改善案

**タイトル**
```
建設業許可の申請代行｜愛知県稲沢市・一宮市の行政書士久遠事務所
```

**説明文**
```
愛知県の建設業許可を稲沢市の行政書士が代行します。新規143,000円〜・更新55,000円・決算変更届33,000円・経審165,000円と料金を公開。相談無料、LINEなら夜間・土日も対応。稲沢・一宮・津島・清須など尾張西部から県内全域まで。
```

**H1**（SIRIUS2でトップのH1をサイト名から変えられる場合）
```
愛知県の建設業許可申請を代行｜稲沢市の行政書士久遠事務所
```

**中身の追加・修正**
1. **住所が二重**：`愛知県稲沢市愛知県稲沢市平和町…` → 1回に
2. **対応エリアの書き方がそろっていない**：本文は「愛知県全域」、運営者情報は「愛知県・三重県・岐阜県」。どちらかに統一
3. **「対応エリア」ブロックを追加**：稲沢市・一宮市・津島市・清須市・あま市・北名古屋市・江南市・愛西市 を並べ、地域ページができたらリンク（古物商の変更届ページには既に尾張エリアの一覧があるので、それを参考に）
4. **「建設業以外の許可」ブロックを追加**：古物商許可（category10/）・産廃収集運搬（category11/）へのカード。今は運営者情報の文中に文字だけで、リンクがない。サイトの表示の約4割は古物商なので、古物商で来た人をトップ経由で回遊させる入口にもなる
5. 依頼実績（件数・業種・地域など、事実の範囲で）があれば「3つの強み」の近くに入れる
6. 構造化データは今 `WebSite` だけ。事務所の情報（名前・電話・対応エリア・営業時間）を `LegalService` として加えると、事務所として認識されやすい（住所を出したくない場合は住所なしでも可）
