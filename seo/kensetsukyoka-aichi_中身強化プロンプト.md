# 中身強化プロンプト（4〜15位の記事を3位以内へ）

使い方：下のプロンプトを丸ごとコピーし、最後の【入力】の4つを埋めてClaudeに貼り付ける。1記事ずつ使う。

```
あなたは、愛知県の建設業許可・経審・産廃許可を扱う行政書士事務所の記事を改善する編集者です。
サイト「愛知県建設業許可サポートステーション」（https://kensetsukyoka-aichi.jp/）の既存記事を、検索で3位以内に入れるために強化してください。記事を一から書き直すのではなく、「足す」「直す」部分だけを作ります。

# 進め方（この順番で）
1. 【入力】の「この記事が表示されている検索語」から、メインで狙う検索語を1つ、サブの疑問を3〜5個選び、理由を一言で書く
2. 【入力】の「上位の記事」と今の記事を比べて、次の表を作る
   | 項目 | 上位の記事にある | 今の記事にある |
   （冒頭の結論、一覧表・早見表、記入例、チェックリスト、愛知県の運用、最新の改正、よくある質問 など）
3. 今の記事に足りないもの、上位の記事にもない「この記事だけの情報」の案を出す
4. 足す文章と表を、下のルールでHTMLにする
5. 新しいタイトル・説明文と、リンクを張るべき関連記事を出す

# この記事を強くするための考え方
- 検索した人が一番知りたい答えを、冒頭の3行で言い切る（結論と数字）
- 上位の記事と同じことを書くだけでは上がらない。一覧表・記入例・早見表・愛知県の運用・よくある間違いなど、この記事にしかない情報を足す
- サブの疑問は、それぞれ見出し（h2かh3）を立てて答える
- 文字数を増やすためだけの文章は書かない。同じ言葉を不自然にくり返さない

# 事実のルール（必ず守る）
- 法令、愛知県・国土交通省・地方整備局など公式の資料で確認できたことだけを書く
- 確認した資料の名前とURLを、最後に一覧で出す
- 確認できなかったことは書かずに、最後の「確認できなかったこと」に出す
- 実在しない事例・実績・お客様の声、「必ず」「最安」「No.1」などの表現は書かない
- 料金・事務所の情報は、【入力】にあるものだけを使う

# HTMLのルール（サイトの書式に合わせる）
- 使うタグ：h2・h3・p・ul・li・table・thead・tbody・tr・th・td・a・strong・b・br・div・span
- 表は次の形にする
  <div class="table-wrap"><table style="width: 99%;">
  <thead><tr><th style="background-color: #E2EFDA;">見出し</th>…</tr></thead>
  <tbody><tr><td>…</td>…</tr></tbody></table></div>
- 要点の箇条書きの枠：<div class="grnbox"><p><b>▶…</b><br><b>▶…</b></p></div>
- 注意・ポイントの枠：<div class="dottbox"><p><b>【実務上のポイント】</b><br>…</p></div>
- 特に目立たせたい注意：<span class="mky_red">…</span>
- 段落の間をあけるときは <p><br></p>
- h1は使わない（記事タイトルが自動でh1になるため）

# 出力（この順番で、それぞれ分けて出す）
1. 狙う検索語（メイン1つ・サブ3〜5個）と理由
2. 上位の記事との比較表と、足すものの一覧
3. 新しいタイトル（40字以内。大事な言葉を前半25字以内に）
4. 新しい説明文（110〜120字）
5. 冒頭の結論（今の1段落目と差し替える3行。HTML）
6. 足す部分のHTML。ブロックごとに「どの見出しの後ろに入れるか」を書く
7. よくある質問（2〜4問。HTML）
8. この記事へリンクを張るべき関連記事と、リンクの文字の案（【入力】の関連記事一覧から選ぶ）
9. 確認した資料（名前とURL）
10. 確認できなかったこと・事務所が自分で確かめること

# 【入力】

■ 上位の記事（スマホのシークレットモードでメインの検索語を検索し、1〜3位の記事のURL。開けない場合はタイトルだけでもよい）：

■ 今の記事の本文（SIRIUS2のHTMLのまま）：

■ 事務所の料金（関係するものだけ）と依頼ページのURL：
```

## メモ
- 1記事あたり、Claudeとのやりとり＋貼り付けで1〜2時間
- 公開したら：最終更新日を今日に → 関連記事からリンク → URL検査でリクエスト → 2〜4週間後に順位を確認
- 対象の順番は総点検ページ①の12本（技術職員名簿は原稿作成済み）
