## 1. タイトル
```
技術職員名簿の業種コード・有資格区分コード一覧｜経審の書き方と記入例
```

## 2. 説明文
```
経審の技術職員名簿（別紙二）で使う業種コードと有資格区分コードを一覧表にまとめました。1人2業種までのルール、講習受講欄、定年後の継続雇用の技術者の扱い、記入例まで、愛知県の建設業者向けに行政書士が解説します。
```

## 3. 冒頭（筆者紹介のすぐ下の1段落目と差し替え）
```html
<p><strong>結論：</strong>技術職員名簿には、業種ごとの<strong>業種コード（2桁）</strong>と、資格ごとの<strong>有資格区分コード（3桁）</strong>を記入します。1人につき記入できるのは<strong>2業種まで</strong>で、点数は資格によって1点〜6点です。よく使う有資格区分コードは、この記事の<a href="#code-list">一覧表</a>で確認できます。</p>
```

## 5. 記入例（「その他の記入欄」の章の前に、新しいH2として）
```html
<h2>技術職員名簿の記入例</h2>
<p>1級土木施工管理技士で、監理技術者資格者証を持ち、監理技術者講習も受けている人を、土木工事業とほ装工事業の2業種で申請する場合の例です。</p>
<div class="table-wrap"><table style="width: 99%;">
<thead><tr><th style="background-color: #E2EFDA;">欄</th><th style="background-color: #E2EFDA;">1業種目</th><th style="background-color: #E2EFDA;">2業種目</th></tr></thead>
```

## 6. 継続雇用の技術者（「名簿に載せられる人」の章の最後に、H3として）
```html
<h3>定年後の継続雇用の技術者は載せられる？</h3>
<p>定年後に、高年齢者雇用安定法の<b>継続雇用制度の適用を受けている技術職員（65歳以下）</b>は、雇用期間が限られていても技術職員として評価されます。そのためには、<b>「継続雇用制度の適用を受けている技術職員名簿」</b>の提出が必要です。常時10人以上の労働者を使用する会社は、継続雇用制度を定めた<b>労働基準監督署の受付印のある就業規則</b>もあわせて提出します。</p>
<p><br></p>
<p>継続雇用制度の対象ではない方や、66歳以上で常勤役員ではない方は、<b>期間を限定せずに常時雇用されていることが分かる雇用契約書</b>で確認します。<span class="mky_red">1年ごとの更新など、雇用期間が限られている場合は、技術職員名簿に載せられません。</span></p>
<p><br></p>
<p>様式や提出方法は、愛知県の経営事項審査の手引で最新のものを確認してください。</p>
```

## 7. よくある質問（「まとめ」の前に追加）
```html
<h2>よくある質問</h2>
<h3>Q. 有資格区分コードに英字が入っているのはなぜですか</h3>
<p>1級・2級の技士補のコードです。たとえば1級土木施工管理技士補は「11H」です。合格後に所定の実務経験がある場合に1点として評価されます。1級技士補で主任技術者の資格もある人は、監理技術者補佐（コード005・4点）として申請できます。</p>
<h3>Q. 1人を3業種以上に載せられますか</h3>
<p>できません。経審で1人の技術職員として申請できるのは2業種までです。どの2業種に割り当てるかで点数が変わるので、会社全体で一番点数が高くなる組み合わせを考えます。</p>
<h3>Q. 第2種電気工事士は何点になりますか</h3>
<p>免状の交付を受けた後、3年の実務経験があれば、電気工事業で1点として評価されます（コード256）。第1種電気工事士は2点です（コード155）。</p>
```
