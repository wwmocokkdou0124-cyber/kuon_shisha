## 依頼ページ（A1）
- タイトル（料金が決まったら「33,000円〜」などを足す）
```
電気工事業の登録・みなし登録の届出代行｜愛知県・稲沢市の行政書士
```
- 説明文
```
電気工事を請け負うには、建設業許可とは別に電気工事業の登録や届出が必要です。登録・みなし登録の届出、主任電気工事士の変更届、実務経験の証明まで、愛知県の手続きを稲沢市の行政書士が代行します。
```

## 記事（作る順）
### 1. 主任電気工事士（C2）
```
主任電気工事士とは？なれる人の要件と、交代・退職したときの変更届【愛知県】
```
```
主任電気工事士は、一般用電気工作物の工事をする営業所ごとに置く責任者です。第一種電気工事士か、第二種＋実務経験3年の人がなれます。交代や退職のときの変更届、後任がいないときの注意点を行政書士が解説します。
```
### 2. 実務経験3年の証明（C3）
```
第二種電気工事士の実務経験3年の証明｜主任電気工事士等実務経験証明書の書き方【愛知県】
```
```
第二種電気工事士で主任電気工事士になるには、免状の交付後3年以上の実務経験の証明が必要です。数え方、証明してくれる人の条件、実務経験証明書の書き方と郵送での提出まで、愛知県の取扱いに沿って行政書士が解説します。
```
### 3. 建設業許可の更新と電気工事業の変更届（C6・新しく追加）
```
建設業許可を更新したら電気工事業の変更届も必要｜みなし登録業者が忘れやすい手続き【愛知県】
```
```
みなし登録電気工事業者は、建設業許可を更新したときにも電気工事業の変更届が必要です。許可の年月日が変わるためで、出し忘れが多い手続きです。届出の時期・書類と、建設業許可の更新とまとめて頼む方法を解説します。
```
### 4. 電気工事業の登録（C1）
```
電気工事業の登録とは？建設業許可のない会社・一人親方が登録する手順【愛知県】
```
```
建設業許可を持っていない会社や一人親方が電気工事を請け負うには、愛知県知事の電気工事業の登録が必要です。登録・通知・みなし登録の違い、営業所ごとの主任電気工事士、器具、必要書類と流れを行政書士が解説します。
```
### 5. 登録の更新（C4）
```
電気工事業の登録の更新｜5年ごとの期限・必要書類と期限切れの注意【愛知県】
```
```
登録電気工事業者の登録は5年ごとに更新が必要です。更新申請の時期、必要書類と手数料、主任電気工事士や器具の確認、期限が切れたときの扱いを解説します。みなし登録の届出に更新がない理由もあわせて整理します。
```
### 6. 認定電気工事従事者（C5・余裕があれば）
```
認定電気工事従事者とは？第二種電気工事士との違い・できる工事・申請方法
```
```
認定電気工事従事者は、自家用電気工作物のうち600V以下で使う部分の工事ができる資格です。第二種電気工事士との違い、講習や実務経験による取り方、申請先を整理し、電気工事業の登録との関係も解説します。
```

※ 書くときに確認すること：愛知県の手数料、変更届の期限、控えをなくしたときの扱い（産業保安室）。説明文の中身は記事を書いたあとに合わせて直す
