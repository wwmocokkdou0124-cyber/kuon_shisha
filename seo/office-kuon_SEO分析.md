## 5. 方針：サイトの作り替え（2026-11-04 決定）

- 本人がいちばんやりたいのは **深夜酒類提供飲食店営業の届出（深酒）** と **風俗営業1号許可**。
- 今は調べもの系（風営法とは・シーシャ）で見られているだけで、依頼を受けるページがない → 問い合わせ0件。
- サイトは消さずに、記事の書き直し・統合・依頼ページ新設で作り替える。建設業サイトと同じく「依頼ページが中心、記事はそこへ流す」形にする。

### 作り替えのルール
- **URLは変えない**。順位や評価がURLに付いているため。
- 記事を消す・まとめるときは、近い記事か依頼ページへ **301転送** する（404にしない）。
- 一度に全部は変えない。**週ごとに5〜10ページずつ** 変えて、変えた日をこのメモに記録する。効果確認は2〜4週間後。
- クリックがあるページ（category2のシーシャ記事、entry46など）は、テーマを変えずに中身を良くする。

### 進め方
| 段階 | やること |
|---|---|
| 0. 棚卸し | 全ページ（約95本）を「残す／書き直す／統合して301転送／後回し」に分ける。サイトへの接続が必要 |
| 1. 土台 | トップページを書き直す。依頼ページを2本作る：【名古屋・愛知】深夜酒類提供飲食店営業の届出代行／【名古屋・愛知】風俗営業1号許可の申請代行（料金・期間・流れ・対応地域・スマホで押せる電話／LINE） |
| 2. 入口の記事 | 表示が多い記事を書き直し、依頼ページへリンク：entry46（風営法とは）、20ルクスの記事、entry6（シーシャ開業）、entry54、entry43 |
| 3. 支える記事 | 依頼ページに直結する記事を足す（例：スナックの接待はどこから1号許可が必要？／バーの深夜営業は届出なしだとどうなる？／深酒の届出に必要な図面／1号許可の要件と場所の制限） |
| 4. 整理 | 依頼につながらない雑多な記事は後回し。かぶっている記事（category2/entry17・39 と category8 など）は統合 |

シーシャ記事の位置づけ：お酒を出して深夜営業するシーシャバーは深酒の届出が必要 → 深酒の依頼ページへの入口として使う。
