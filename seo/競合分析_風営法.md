## 2. 東京：ARUTO（https://toaru.tokyo/lp/）＝型の参考

広告用のLP（1ページ完結）。

- タイトル：「風営法許可申請代行サービス - ナイトビジネス専門 行政書士法人 ARUTO」
- 説明文：最短3日で申請／許可が下りなければ全額返金／セット価格
- ファーストビュー：「書類に印鑑を押すだけ！」「許可が下りなかった場合は全額返金」「初回相談無料・お急ぎ相談ダイヤル（フリーダイヤル）」
- 強み4つを見出しに：**最短当日訪問／年間300件以上／明朗会計（セット価格）／不動産に強い**
- 安心材料：複数の行政書士で対応（担当が倒れても止まらない）、賠償責任保険2億円、代表は元警察官（刑事10年）
- サービス12種類をカード形式で並べ、**全部に「報酬額 ○万円〜」**。業態の例（スナック・ラウンジ・コンカフェ など）も添える
- 「風営法許可の注意点」：行政書士選びでスピードが変わる／どこでも営業できるわけではない（物件契約前に相談）／図面が難しい／オープン後もサポート
- よくある質問8つ：実績／他県対応／依頼のタイミング／許可が要るか分からない／安くならないか／最短いつ／営業時間を延ばしたい／オープン後の相談
- スタッフ紹介（顔・名前・一言）、許可取得したお店の紹介（実績）、ブログ
- 申請の流れ4ステップ、ページ内にお問い合わせフォーム
- おまけ特典：「従業者名簿、18禁プレートサービス」「都内23区交通費無料」

**久遠が真似できること**
- 「全額返金」「最短○日」など、**依頼する不安を消す一言**をファーストビューに置く（返金保証は実際にできる範囲で）
- サービスごとに **「○万円〜」** を必ず出す
- よくある質問に「許可が要るか分からない」「安くならないか」「最短いつ」「物件契約前に相談できるか」を入れる
- 特典（従業者名簿のひな形・18禁プレートなど）
- 実績（許可を取ったお店の紹介）。件数が少ないうちは「シーシャバー勤務経験」を前に出す

## 3. 名古屋の競合＝勝つべき相手

### おおみ行政書士事務所（https://www.ohmi-office.com/ ／ https://ohmi-office.jp/）
- 本体サイトのほかに、**業態・悩みごとのLPを大量に持つ**（例：ohmi-office.jp/business_license/lp5/ キャバクラ、/mid_night/lp31/ バーの深夜営業）
- LPの形はほぼ同じ：H1「（悩み）｜【愛知県・名古屋】おおみ行政書士事務所」→ FAQ → 注意点 → サービス → **料金表（広さ別）** → 流れ → 事務所紹介 → 問い合わせ → 関連記事
- 電話番号と受付時間（10:00〜20:00）を料金表のすぐ下に
- 名古屋を中心に幅広いエリアに対応、と地域を明記

### ひおり行政書士事務所（https://hiori5150.biz/）
- タイトル：「ひおり行政書士事務所｜名古屋市」、説明文：「名古屋市で風俗営業許可を専門とした行政書士事務所」
- **愛知・岐阜・三重・静岡の全域スピード対応**
- サービス案内：1号・5号・特定遊興・深酒・ポーカーバー・たばこ・4号・無店舗型（業態の例つき）
- **5坪刻みの細かい料金表**（1号：33㎡未満 99,000円〜／深酒：33㎡未満 77,000円〜）、注意書き（保全対象施設の調査は別料金など）
- LINEを2か所で大きく案内、対応エリアを明記、実績報告ページあり

### 行政書士浅野事務所（https://fuuei.asano-office.com/）
- 風営法専用のサイト。メニューは 社交飲食店／深夜酒類／麻雀店／パチンコ店
- 報酬額表ページはあるが、1号は「個別見積もり」。**簡易見積もりフォーム**と電話番号を目立たせる
- 深酒のページに **図面の例** を載せている

### その他
- 小林総合事務所：不動産・運送・在留など総合型。風営法は一部（強い競合ではない）
- 和虎行政書士法人：東京・関東が中心の格安型。名古屋の直接の競合ではない

## 4. 久遠の立ち位置

| 項目 | 競合 | 久遠 |
|---|---|---|
| 料金 | 広さ別で公開、深酒 8〜9万円・1号 10〜11万円〜 | 深酒 165,000円、1号なし |
| 専門性の見え方 | 風営法専用サイト or 専用LP | トップは6分野の何でも屋 |
| 記事の量・質 | おおみ以外は少なめ | **133本と多く、愛知の一次情報にもとづく。ここは勝っている** |
| 現場経験 | 和虎「元1号店経営者」、ARUTO「元警察官」 | **シーシャバー勤務経験**（まだ前に出し切れていない） |
| 対応エリア | 愛知全域〜東海4県 | 愛知県全域 |
| 問い合わせ導線 | 電話・LINE・フォーム | 同じくあり（ただしリンク切れあり） |

**結論**：記事の中身は名古屋の競合に勝っている。足りないのは **①1号の依頼ページと料金 ②深酒の料金の見直し（か、高い理由の説明）③専門家に見えるトップページ**。

## 5. 依頼ページの設計図（深酒・1号 共通）

1. ファーストビュー：【愛知・名古屋】○○の申請代行／相談無料・土日夜間OK・LINE／不安を消す一言（例：物件契約前の無料調査）
2. こんな方へ（業態の例：バー・シーシャバー・居酒屋／スナック・ラウンジ・キャバクラ・コンカフェ・ガールズバー）
3. 久遠に頼む理由3つ（シーシャバー勤務経験・図面を自分で作成・警察署同行 など）
4. **料金表（広さ別）**＋含まれるもの／別になるもの（手数料24,000円 など）
5. 申請の流れと期間（深酒：営業開始10日前まで／1号：標準処理期間55日）
6. 許可が取れない場所の注意（用途地域・保全対象施設）→ 物件契約前に相談を
7. よくある質問（要るか分からない／安くならないか／最短いつ／自分でやる場合との違い）
8. 対応地域（名古屋市の区・尾張・三河）
9. 問い合わせ（電話・LINE・フォーム）＋関連記事（深酒⇔1号を相互に）
